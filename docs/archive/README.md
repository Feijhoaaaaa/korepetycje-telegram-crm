# Archiwum

Ten katalog zawiera historyczne prompty, specyfikacje i metadane narzędzi używane
podczas wcześniejszego rozwoju projektu. Materiały mogą być nieaktualne i nie są
źródłem prawdy dla działania aplikacji. Aktualne informacje znajdują się w głównym
`README.md`, kodzie, migracjach i `docs/OPERATIONS.md`.
